# Run 3 (partial smoke check) — current model

**Model:** `openai/gpt-oss-120b` via Groq, low reasoning effort, run through the deployed app's `/api/copilot` endpoint (single-turn, fresh conversation per question).
**Scope:** 4 conversation turns covering 6 of the 22 golden rows (A1–A4, C3, D1). **This is not a full re-run.** The other 16 rows have not been re-tested on this model.
**Scored against:** the official GOV.UK fee figures for the fee rows (see the correction block in `golden-questions.md`); the reviewer's own knowledge for the rest (unverified). Single rater. Only the `verified` section is scored, as in Runs 1–2.

**Result: 6 of 6 rows checked were correct in the `verified` section.** On the fee rows this is the outcome the grounding was designed to produce, now against figures checked with the official tables, and it shows the fee grounding survived the model change.

## What this does not show

- It is 6 rows, one run each, one rater. It says nothing about the other 16 rows on this model.
- **The `community` section was not scored, and it is a weak spot.** It is generated by the model rather than taken from real applicant posts. In the D1 answer it claimed travel insurance "helps with NHS surcharge exemptions", which is unsupported. In the A3/A4 answer its advice about children travelling on an adult's visa contradicted itself. Neither error was in the `verified` section, so neither affects the scores above, but both are the kind of confident-sounding mistake a user could act on.
- The C3 answer put a "£1,000–£1,500 per month" figure in `community` and a "£1,200 × months" example in `recommendation`. The number is correctly kept out of `verified`, but it is still an invented figure presented to the user.
- Non-fee reference answers remain unverified against GOV.UK.
